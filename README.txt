Arquivos incluídos:
- index.html
- servicos.html
- sobre.html
- contato.html
- css/styles.css
- js/script.js
- assets/eliab.jpeg  (logo copiada do upload)

OBS: Substitua o link do WhatsApp nas páginas (atualmente usa um número exemplo: 5599999999999).
Se quiser seu número real, troque o href da classe .whatsapp-float para:
https://wa.me/55<DD><NUMERO>

Como testar localmente:
1. Extraia o ZIP e entre na pasta.
2. Abra index.html no navegador.

Como publicar no Vercel (resumo):
1. Crie um repositório no GitHub e envie todos os arquivos.
2. Em vercel.com, clique em New Project → Import Git Repository.
3. Selecione o repositório e clique em Deploy (projeto é estático, sem build command).
4. Depois do deploy, configure domínio se quiser.
